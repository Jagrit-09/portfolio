SwiftTicket

A one-handed ticketing app for bus conductors. The brief: select a destination and issue tickets for 3 passengers in under 4 seconds, on a moving bus, in glare, with cash in the other hand.

I put stop, passenger count and fare on one screen, kept the main actions in the thumb zone, and built a clickable prototype with a built-in timer. It also covers printer failure, offline tickets, low battery, voids and a high-glare mode.

I built the REST API and the real-time layer from scratch with Node.js's HTTP module and Server-Sent Events. The matching logic is unit tested and the data layer is ready for a database.
