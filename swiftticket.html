Test protocol

  1. Start stopwatch.
  2. Select a familiar destination.
  3. Set passenger count to 3.
  4. Issue the ticket; stop when confirmation is visible.
  5. Repeat 10 times and report median, errors and handedness.

Design choices

  • Each new ticket starts at 1 passenger.
  • Recent routes stay visible on the screen.
  • The destination, passenger count and fare stay visible before issue.
  • Void, reprint and offline options are examples.

Sample routes and fares are used in this demo. This is not a live ticketing system.
